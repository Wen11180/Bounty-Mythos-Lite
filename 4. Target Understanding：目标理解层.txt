这是你接近 Mythos 的第一关键。

系统不是直接扫，而是先生成：

program_security_map.md
api_object_model.json
role_permission_matrix.json
business_flow_graph.json
sensitive_action_index.json

它会理解：

- 有哪些用户角色
- 有没有组织/团队/租户
- 哪些资源是敏感对象
- 哪些接口是读/写/删除/邀请/导出
- 哪些参数像 user_id、org_id、team_id、file_id、invoice_id
- 哪些流程涉及支付、退款、邀请、权限、文件分享

OWASP API Security Top 10 2023 里，Broken Object Property Level Authorization、Broken Authentication、Unsafe Consumption of APIs 等都属于 API 安全重点风险；这说明最终版应该优先围绕 API 授权边界和对象级权限建模。
